# 我的AI工具箱：2026年模型选型与使用心得

> 作为一名CS学生，AI工具已经成为我日常学习、编程和创作的得力助手。这篇文章总结了我目前使用的AI工具栈，以及选型时的一些思考。

---

## 一、问答模型：日常学习与知识获取

### 主推：Gemini 2.5 Pro

**为什么选它？**

Gemini 2.5 Pro 是我目前日常问答的首选。它的优势在于：

- **超长上下文**：支持1M+ token的上下文窗口，可以一次性处理整本书、整个代码库或长论文
- **多模态理解**：不仅能读文字，还能分析图片、图表，甚至视频内容
- **Google生态整合**：与Google搜索、Gmail、Docs等工具无缝衔接

**使用场景：**

- 读论文时快速提取核心观点
- 整理课程笔记，生成思维导图
- 跨学科知识查询（比如"用通俗语言解释Transformer"）

**Benchmark表现：**

| 测试集           | Gemini 2.5 Pro | GPT-4o | Claude 3.5 Sonnet |
| :--------------- | :------------- | :----- | :---------------- |
| MMLU (知识理解)  | 89.7%          | 88.7%  | 88.5%             |
| MMMU (多模态)    | 75.0%          | 69.1%  | 68.3%             |
| HumanEval (代码) | 85.7%          | 90.2%  | 92.0%             |

> 数据来源：各厂商官方技术报告及LMSYS Arena公开数据

## 二、Code Agent：编程助手选型

### 第一梯队：Claude Code + GPT-5.5

**Claude Code**

Claude Code 是目前最强的编程Agent之一，特别是在：

- **代码理解深度**：能处理复杂代码库，理解项目架构
- **Refactoring能力**：重构代码时考虑上下文依赖
- **Debug能力**：定位bug的准确率很高

**⚠️ 注意：封号风险**

Claude对账号风控较严格，特别是：

- 频繁切换IP
- 使用共享账号
- 大量自动化请求

**建议：** 如果追求稳定，优先考虑GPT Plus/Pro，封号风险更低。

**GPT-5.5 (Code Interpreter)**

OpenAI的代码能力一直在第一梯队：

- **工具调用丰富**：支持文件读写、数据分析、图表生成
- **稳定性高**：API稳定，适合生产环境
- **生态成熟**：与GitHub Copilot、VS Code深度整合

### 预算有限？Copilot Pro是性价比之选

如果你每月预算在$20以内：

- **GitHub Copilot Pro** ($19/月)：代码补全最强，适合日常编码
- **ChatGPT Plus** ($20/月)：通用能力强，代码也不错
- 两者选其一，优先Copilot Pro if you code more

## 三、API选型：官方 vs 国内代理

### 官方渠道

**适合人群：** 追求稳定、有海外支付能力

- **OpenAI API**：最成熟，文档完善，生态丰富
- **Google AI Studio**：Gemini API免费额度 generous
- **Anthropic API**：Claude官方，但风控严格

### 国内模型：性价比之选

**Kimi 2.6 (Moonshot)**

- **价格优势**：200元套餐可拼单，适合学生党
- **长文本强项**：支持200万字上下文
- **建议按月买**：国内模型升级快，按需购买最新版

**DeepSeek V4 Pro**

- **当前性价比之王**：价格打2.5折（截至5月底）
- **效果超预期**：在多个benchmark上接近第一梯队
- **适合尝鲜**：低成本体验顶级模型

**Benchmark对比（国内模型）：**

| 模型            | MMLU  | C-Eval (中文) | 价格(每1M token) |
| :-------------- | :---- | :------------ | :--------------- |
| DeepSeek V4 Pro | 87.2% | 91.5%         | ¥0.5 (2.5折)     |
| Kimi 2.6        | 85.8% | 89.2%         | ¥1.2             |
| GPT-4o          | 88.7% | 86.1%         | $5.0             |

> 价格数据截至2026年5月，具体以官方为准

## 四、我的个人工具栈

## 写在最后

AI工具迭代很快，我的建议：

1. **不要锁定单一模型**：不同任务用不同工具
2. **关注性价比**：学生党优先免费/低价选项
3. **按月订阅**：模型升级快，灵活调整
4. **多尝试**：新模型出来时先试用再决定

> _"工具是手段，解决问题才是目的。选最适合自己的，而不是最贵的。"_
